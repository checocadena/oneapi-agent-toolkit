DESCRIPTION (one paragraph)

Intel's SYCLomatic gets CUDA code most of the way to SYCL, an open standard not tied to NVIDIA, but it leaves the output full of helper code and gives no proof that the port still behaves like the original. oneapi-agent-toolkit gives a coding agent five tools that return evidence instead of claims (migrate, compile, scan_helpers, verify and benchmark), through an MCP server, a command line or a bundled agent loop, and counts a port as done only when its output matches the original and no helpers remain. In 120 measured runs with two Claude models, agents using the toolkit finished every port correctly (40 of 40), while the same agents without its checks managed 23 of 40; on five programs the agent had never seen, the result was 30 of 30 against 18 of 30, and the agent's unedited ports then passed on rented NVIDIA and AMD GPUs. The toolkit is a working research tool at version 0.3.0, not yet on PyPI. Its results so far come from Claude models only, on small programs graded on a CPU: indicative, not a benchmark. Muse Port, by the same author, is built on it.
