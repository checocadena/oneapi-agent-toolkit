Agent's final claim
Ported to SYCL 2020 with no dpct headers or helpers. Compiled cleanly with add_dpct_include=false. I did not run the binary or compare its output with the reference. - **Sub-group size:** softMax2 uses `reduce_over_group` on the sub-group, and the sub-group size is not hard-coded to 32. The grid is sized for the device's smallest supported sub-group size, so surplus sub-groups exit early. That is wasteful when the runtime picks a larger sub-group. - **Precision:** `sycl::exp` replaces the `native::exp` that c2s generated, to stay within the 1e-6 tolerance. - **Launch:** both kernels use 1-D `nd_range` launches.
